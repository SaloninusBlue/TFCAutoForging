# TFC 自动锻造 · 白名单增强版

[English](README.md)

一个群峦传说 TFC:TNG 的客户端模组，在原版自动锻造基础上增加了操作激活、白名单和速度控制。  
基于 Eternal130 的 [TFC Auto Forging](https://github.com/Eternal130/TFCAutoForging) 二次开发。

## 功能

1. **自动锻造** — 进入铁砧界面后自动识别并执行最优锻造步骤。
2. **操作激活模式** — 在"禁用"和"全自动"之间的折中选择。  
   选定配方后不立即锻造，等你手动敲第一下确认，模组再接管剩余步骤。
3. **目标物品白名单** — 指定哪些配方产物可以享受特殊策略。  
   白名单内外可以分别设置不同的自动化策略。
4. **锻造速度可调** — 极快 / 快 / 适中 / 稳妥四档可选。
5. **锻造提示** — 在铁砧按钮上高亮显示推荐步骤。
6. **游戏内设置面板** — 按 **Ctrl+F** 打开，可看到背包物品，右键加入白名单，一键切换策略和速度。

## 按键

| 按键 | 功能 |
|------|------|
| **F** | 开关自动锻造 |
| **Ctrl+F** | 打开设置面板 |
| **G** | 开关锻造提示高亮 |

## 设置面板 (Ctrl+F)

- **白名单内** — 白名单配方策略：操作激活 / 全自动
- **白名单外** — 非白名单配方策略：永不 / 操作激活 / 全自动
- **速度** — 锻造间隔：极快（一帧一敲）/ 快 / 适中 / 稳妥（~1 秒）
- **3×3 白名单槽位** — 右键背包物品直接加入；左键拿起/交换；右键白名单槽清空
- 所有修改即时保存，按 ESC 关闭

## 安装

提供两个版本：

### Minecraft 1.20.1 (Forge)
- 需要：**Forge 47.x** + **TFC TNG 3.x（1.20.1 版）**
- 下载：`tfcafww-tfctng-1.20.1-0.3.jar`

### Minecraft 1.21.1 (NeoForge)
- 需要：**NeoForge 21.1.x** + **TFC TNG（1.21.1 版）**
- 下载：`tfcafww-tfctng-1.21.1-0.3.jar`

纯客户端模组，服务器不需要安装。
